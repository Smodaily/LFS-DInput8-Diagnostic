LFS DInput8 Diagnostic Proxy — исходный проект x64

Назначение
----------
Это диагностическая DLL-прокладка. Она проверяет, вызывает ли процесс игры
DirectInput8Create, и записывает результат в LFS_Assist.log рядом с DLL.
Она НЕ меняет ось руля и пока НЕ является готовым Steering Assist.

Сборка
------
1. Установить Visual Studio 2022 с workload «Разработка классических
   приложений на C++» и компонентом Windows 10/11 SDK.
2. Открыть LFS_DInput8_Diagnostic.vcxproj.
3. Выбрать конфигурацию Release и платформу x64.
4. Выполнить Build -> Build Solution.
5. Готовая DLL появится в bin\Release\dinput8.dll.

Проверка
--------
1. Закрыть LFS.
2. Сделать резервную копию файлов игры, если рядом с LFS.exe уже есть dinput8.dll.
   Ничего существующего не перезаписывать.
3. Скопировать собранную dinput8.dll в папку рядом с LFS.exe.
4. Запустить LFS, зайти в настройки управления, подвигать левый стик,
   затем закрыть игру.
5. Проверить LFS_Assist.log рядом с DLL.

Важно
-----
- Если лог появился и содержит «called DirectInput8Create», это подтверждает,
  что игра прошла через DirectInput 8.
- Если лога нет, это ещё не доказывает, что DirectInput не используется:
  игра могла не загрузить локальную прокладку или использовать другой API.
- Для удаления достаточно закрыть игру и убрать только нашу dinput8.dll.
- DLL загружает оригинальную системную библиотеку по полному пути из System32.
- Это исходный код; готовый бинарник в архив не включён.
